# Development and publication

`index.client.tsx` registers the React Native workspace/explorer panel. `index.server.ts` resolves the workspace through Paseo and routes validated RPCs to the GitHub adapter. The SDK is pinned to 0.16.1; compatibility is restricted to the 0.16 series until later versions are tested.

Source publication, a tagged GitHub release, and Paseo registry approval are separate stages. Registry listing requires a screenshot of the working panel and review of a pinned source revision. This project is independently maintained and is not an official Paseo product.
